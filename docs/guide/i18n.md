# 国际化

Mote UI 内置组件级国际化机制：通过 `ConfigProvider` 注入语言包，默认中文（`zhCN`），附带英文语言包（`enUS`）。所有内置文案（Dialog/Picker 按钮、Empty 描述、Image 错误提示、表单校验消息）均接入 locale。

## 使用 ConfigProvider

```vue
<script setup lang="ts">
import { MtConfigProvider, enUS } from 'mote-ui'
</script>

<template>
  <MtConfigProvider :locale="enUS">
    <!-- 后代组件文案自动切换为英文 -->
  </MtConfigProvider>
</template>
```

::: tip
`ConfigProvider` 会同步全局 locale，因此 `confirmDialog` / `alertDialog` 等函数式 API 也会跟随最后一次配置的语言包。
:::

## 全局切换

不使用 `ConfigProvider` 时，可直接调用 `setLocale` 切换全局语言包：

```ts
import { setLocale, enUS } from 'mote-ui'

setLocale(enUS)
```

## 自定义语言包

语言包结构为 `MtLocaleMessages` 类型，可整体替换，也可基于内置语言包扩展：

```ts
import type { MtLocaleMessages } from 'mote-ui'
import { enUS } from 'mote-ui'

const myLocale: MtLocaleMessages = {
  ...enUS,
  empty: { description: 'Nothing here yet' },
}
```

校验消息支持占位符插值：`form.range` / `form.min` / `form.max` 中的 `{min}`、`{max}` 会在运行时替换为规则值。

## 内置语言包

| 语言包 | 标识 |
| --- | --- |
| `zhCN` | 简体中文（默认） |
| `enUS` | 英文 |

## 覆盖范围

| 文案 | locale 路径 |
| --- | --- |
| 确认 / 取消按钮（Dialog、Picker） | `common.confirm` / `common.cancel` |
| Empty 默认描述 | `empty.description` |
| Image 加载失败提示 | `image.error` |
| 表单校验消息 | `form.*` |

组件上显式传入的文案 prop（如 `confirm-button-text`、`description`）优先于 locale。
