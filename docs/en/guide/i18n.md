# Internationalization

Mote UI ships with a built-in component-level i18n mechanism: inject a language pack via `ConfigProvider`. Chinese (`zhCN`) is the default, and an English pack (`enUS`) is bundled. All built-in texts (Dialog/Picker buttons, Empty description, Image error text, form validation messages) are locale-aware.

## Using ConfigProvider

```vue
<script setup lang="ts">
import { MtConfigProvider, enUS } from 'mote-ui'
</script>

<template>
  <MtConfigProvider :locale="enUS">
    <!-- Descendant component texts automatically switch to English -->
  </MtConfigProvider>
</template>
```

::: tip
`ConfigProvider` also syncs the global locale, so imperative APIs like `confirmDialog` / `alertDialog` follow the last configured language pack.
:::

## Global Switch

Without `ConfigProvider`, switch the global locale directly with `setLocale`:

```ts
import { setLocale, enUS } from 'mote-ui'

setLocale(enUS)
```

## Custom Language Packs

A language pack is typed as `MtLocaleMessages` — replace it entirely, or extend a built-in pack:

```ts
import type { MtLocaleMessages } from 'mote-ui'
import { enUS } from 'mote-ui'

const myLocale: MtLocaleMessages = {
  ...enUS,
  empty: { description: 'Nothing here yet' },
}
```

Validation messages support placeholder interpolation: `{min}` / `{max}` in `form.range` / `form.min` / `form.max` are replaced with rule values at runtime.

## Built-in Language Packs

| Pack | Identifier |
| --- | --- |
| `zhCN` | Simplified Chinese (default) |
| `enUS` | English |

## Coverage

| Text | Locale path |
| --- | --- |
| Confirm / Cancel buttons (Dialog, Picker) | `common.confirm` / `common.cancel` |
| Empty default description | `empty.description` |
| Image load-failure text | `image.error` |
| Form validation messages | `form.*` |

Explicit text props on components (e.g. `confirm-button-text`, `description`) take precedence over the locale.
